# MindClear 🌿
A private, non-custodial self-care journaling and thought-venting web application built with React, Vite, and Tailwind CSS.

### Features
- **Brain Dump:** Release loops and worries with a disappearing ink animation.
- **The Weather Inside:** Quick, wordless mood check-ins.
- **3-Line Reset:** Focus on a stress point, a small win, and gratitude.
- **Procedural Ambient Audio:** Built-in Web Audio API generator for rain, cafe, and fire sounds.
- **100% Non-Custodial:** All entries and data remain safely inside your browser's local storage.

### Legal & Privacy
- **Age Requirement:** Users must be 13 years or older.
- **Disclaimer:** MindClear is a mindfulness tool and is not a substitute for professional medical advice or therapy.
